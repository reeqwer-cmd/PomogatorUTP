# 🎛️ Task Launcher Suite (Client + Admin Configurator)

Модульный программный комплекс для организации рабочего пространства инженеров технической поддержки и системных администраторов. Позволяет структурировать доступ к служебным скриптам, утилитам и документам через динамически настраиваемый интерфейс в едином темном стиле. По факту должно лежать изначально в папке 2 .exe файла - помогатор и конфигуратор. Для того чтобы в одном настраивать и подключать необходимые инструменты - а фаил помогатора исключительно для запуска и рабочей части.

---

## 🏛️ Архитектура комплекса

Комплекс состоит из двух компонентов, взаимодействующих через общий JSON-манифест:

1. **`pomogator_utp.py` (Client Launcher)** — компактная панель быстрого доступа для конечного пользователя. Отображает вкладки и кнопки запуска в режиме «только чтение», предотвращая случайное повреждение конфигурации.
2. **`configurator.py` (Admin Panel)** — визуальный GUI-конструктор. Позволяет создавать/удалять вкладки, перепривязывать пути к файлам и настраивать кнопки запуска.
3. **`my_config.json`** — файл конфигурации с поддержкой автоматического вычисления относительных путей для переносимости между рабочими станциями.

---

## ✨ Возможности

* **Динамическая генерация GUI:** интерфейс автоматически перестраивается при чтении структуры из конфигурационного JSON.
* **Кастомные адаптивные вкладки:** реализация прокручиваемых контейнеров на связке `tk.Canvas` + `<MouseWheel>`, устойчивая к сбоям отрисовки шрифтов.
* **Интеграция с системным буфером обмена:** копирование файлов в буфер ОС через вызов PowerShell API (`Set-Clipboard -LiteralPath`).
* **Относительные пути:** утилиты можно запускать со съемных носителей или общих сетевых дисков без жесткой привязки к буквам томов.

## 🚀 Установка и запуск

📖 Руководство пользователя

Комплекс спроектирован по принципу разделения прав: администратор один раз настраивает окружение через Конфигуратор, после чего конечные специалисты работают исключительно через легковесный Помагатор.

Для корректной работы оба исполняемых файла (Configurator.exe и PomogatorUTP.exe) должны находиться в одной общей директории рядом со служебным файлом my_config.json.

📁 PomogatorUTP/
 ├── ⚙️ Configurator.exe      # Модуль настройки (запускается администратором)
 ├── 🚀 PomogatorUTP.exe      # Рабочий лаунчер (запускается оператором)
 └── 📄 my_config.json        # Конфигурация интерфейса и ярлыков (При первом запуске он создаст его автоматически)
 
Этап 1. Настройка панели через Configurator.exe

Запусти файл Configurator.exe. Интерфейс разделен на создание категорий (вкладок) и привязку самих ярлыков запуска.

Создание и управление вкладками:

    В поле «Название вкладки» введи имя раздела (например: Диагностика сети, Базы данных или Служебные утилиты).

    Нажми «Добавить вкладку» — появится новый таб в рабочей зоне.

    Чтобы переключиться между категориями, просто кликни по нужному табу.

    Чтобы удалить ненужную категорию со всеми вложенными элементами, открой её и нажми «Удалить вкладку».

Добавление кнопок запуска:

    Перейди во вкладку, куда требуется добавить инструмент.

    В блоке добавления элемента заполни:

        «Название кнопки» — отображаемый текст (например: Пинг весов, Проверка провайдера).

        «Путь к файлу / скрипту» — нажми кнопку «Обзор» (Browse) и укажи исполняемый файл (.exe), скрипт (.py, .bat, .ps1) или документ.

    Нажми «Добавить кнопку».

    По завершении настройки нажми кнопку «Сохранить конфигурацию». Все относительные пути будут автоматически рассчитаны и зафиксированы в my_config.json.


Этап 2. Ежедневная работа через PomogatorUTP.exe

Запусти PomogatorUTP.exe. Программа считает созданный конфиг и построит защищенное рабочее место без лишних элементов управления.

    Навигация по разделам: переключайся между вкладками верхнего меню для доступа к сгруппированным сервисам.

    Запуск инструмента: кликни левой кнопкой мыши (ЛКМ) по плитке нужного инструмента. Приложение запустит целевой процесс в фоновом режиме, не блокируя основной лаунчер.

    Копирование файла в буфер: если кнопка привязана к шаблону, документу или логу, нажми по ней правой кнопкой мыши (ПКМ) — путь или сам файл скопируется в системный буфер обмена Windows для быстрой вставки.

    Прокрутка списков: если в одной категории создано много кнопок, используй колесо мыши (MouseWheel) над рабочей областью для вертикального скроллинга.
